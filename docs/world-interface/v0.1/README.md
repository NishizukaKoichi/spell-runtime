# World Interface Specification v0.1 — published design draft

エージェントネイティブ・サービスの共通契約を提案する、実装前の仕様スナップショットです。企業側は情報と能力を機械可読で提供し、本人側のエージェントが条件・権限・実行・結果をつなぎます。

仕様作成：2026-09-08。GitHub公開用整理：2026-09-09（Australia/Sydney）。公認標準、稼働サービス、安全性認証、既存プロトコルとの相互運用を主張するものではありません。

## Codexの入口

まず [CODEX_IMPLEMENTATION.md](CODEX_IMPLEMENTATION.md) を読み、[SPEC-ja.md](SPEC-ja.md)、[schemas/wis.schema.json](schemas/wis.schema.json)、[openapi.json](openapi.json)、[examples/](examples/)、[tests/validate.py](tests/validate.py) を参照してください。

実装指示書の目的は、仕様の再要約ではなく、サイトを手動操作しない最小の実物を作り、実行・停止・再開・検証まで試すことです。公開だけではCodexタスクは起動しません。対象ブランチを取得した環境、またはこの資料を読める環境で、別途実装タスクとして指示してください。

このディレクトリの公開場所は `NishizukaKoichi/spell-runtime` の `docs/world-interface-v0.1` ブランチです。これは仕様の保管場所であり、WISの全実装を既存Spell Runtimeへ強制的に組み込む決定ではありません。実装開始時に参照コミットSHAを記録してください。

## 内容と検証

23種類のデータ構造と、11件の合成サンプル（ほかにindex）を収録しています。JSONファイルは転送用に整形を圧縮していますが、元の草案と同じデータです。SPEC-ja.mdとテストコードは元の内容を保持しています。

Python 3.10以降を使用し、このディレクトリで実行します。

```sh
python -m pip install 'jsonschema>=4.18,<5'
python tests/validate.py
```

同梱の23テストは構造、内部参照、資源分離と少数の安全性モデルを検証するものです。詳細は [VALIDATION.txt](VALIDATION.txt)。本番ランタイム、OAuth、署名、実決済、障害復旧、相互運用の合格を意味しません。

## 変えてはいけない区別

お小遣いは外部の購入・契約のための金銭。エネルギーはAIの推論・実行のためのトークンです。別台帳で管理し、暗黙に交換しません。本人の総残高はサービスへ公開しません。権限の参照文字列は資格情報ではありません。

`.example` ドメイン、ID、金額、日時、ゼロ埋めダイジェストは架空の説明用データです。実装でそのまま信用・購入・送信に使わないでください。テスト内のメモリー上のモデルは本番部品ではありません。
